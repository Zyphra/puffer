# PUFFER

PUFFER — **P**rovenance-aware **U**pdatable **F**uzzy **F**iltering for
**E**volving **R**epositories — is a Python package for incremental
MinHash-LSH deduplication of growing parquet corpora. It keeps a
persistent, disk-backed index across
dataset releases, so each new release is deduplicated against the full history
without rebuilding a monolithic snapshot — in bounded memory, on one machine or
across a Ray cluster.

## Install

PUFFER requires Python 3.10+.

```bash
git clone https://github.com/Zyphra/puffer.git
cd puffer
python3 -m venv .venv && source .venv/bin/activate
python -m pip install .          # add ".[ray]" for multi-node execution
```

## Quickstart

```python
from puffer import Deduper, PufferConfig

dd = Deduper("state/", PufferConfig(num_bands=8, tier_fanout=4))
report = dd.ingest(["release0/*.parquet"], dataset="release0",
                   output_dir="out/release0")
dd.withdraw("release0")
```

- `Deduper.ingest(inputs, dataset, output_dir)` — deduplicate a release against
  all prior history. Takes input files or glob patterns, a dataset tag, and an
  output directory; writes one deduplicated parquet per input and returns an
  `IngestReport` with per-stage removal counts.
- `Deduper.withdraw(tag)` — remove a dataset's contribution from the index and
  delete its artifacts, returning a `WithdrawReport`. This does not rewrite
  other releases' already-written outputs; future ingests stay correct.

See `examples/` for complete, runnable scripts against synthetic data (run
`examples/make_toy_data.py` first).

## Withdrawal

`Deduper.withdraw(tag)` is the cheap default: it removes the dataset's footprint
from the index and deletes its artifacts, but leaves other releases' existing
outputs as-is.

For **corpus-faithful** withdrawal — surviving outputs and index reproduced as
if the dataset had never been ingested — two functions emit a corrected state at
a new directory for the caller to adopt (both require `record_replay_manifest=True`
at ingest):

- `rebuild_survivors(state_dir, tag, dest_state_dir, cfg)` — reference rebuild;
  replays every surviving release from its content-verified manifest.
- `rebuild_survivors_suffix(state_dir, tag, dest_state_dir, cfg)` — faster path
  that reuses the unaffected prefix and replays only later releases. Requires
  retained prefix outputs/sidecars; use `record_row_signatures=True` to skip
  re-shingling on replay.

Withdrawing a dataset whose keys were compacted into merged index segments
rebuilds those segments with a small C kernel compiled from `_kway.c` on first
use; this requires a C compiler (`gcc`) on `PATH`.

## Configuration

`PufferConfig` fields. Immutable fields are validated against
`state/puffer_config.json` on every call and raise on mismatch; to change one,
start a fresh state directory.

| Field | Default | Immutable | Meaning |
|---|---|---|---|
| `num_perm` | `64` | yes | MinHash permutations (signature length). |
| `num_bands` | `8` | yes | LSH bands; `num_perm % num_bands` must be `0`. |
| `ngram_type` | `"char"` | yes | Shingle kind: `"char"` or `"word"`. |
| `ngram_size` | `20` | yes | Shingle length, in characters or words. |
| `seed` | `42` | yes | MinHash seed. |
| `tier_fanout` | `4` | yes | Tiered-compaction fanout `T`. |
| `ram_budget_bytes` | `4 GiB` | no | Advisory working-set budget (not a hard RSS cap). |
| `probe_order` | `"largest_first"` | no | Shard probe order; heuristic only, result is identical. |
| `n_workers` | `0` (→ CPU count) | no | Workers for signature computation and screening. |
| `text_column` | `"text"` | no | Text column name in input parquets. |
| `sig_chunk_rows` | `20_000` | no | Row-batch size; bounds peak resident text. |
| `screen_batch_bytes` | `256 MiB` | no | Cross-screen window, sized by band-key bytes. |
| `ray_max_in_flight` | `0` (auto) | no | Cap on concurrent Ray tasks (`0` = live cluster CPU slots). |
| `record_replay_manifest` | `True` | no | Record per-release replay manifest; required for faithful withdrawal. |
| `record_row_signatures` | `False` | no | Retain per-row band keys so suffix rebuild can skip re-shingling. |

## Ray

Pass `Deduper(..., executor="ray")` to route signature computation and
membership checks through Ray tasks; results are byte-identical to local
execution. Index appends and compaction stay on the driver. Ray is an optional
dependency (`pip install ".[ray]"`).
